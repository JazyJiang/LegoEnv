# App source attribution

The accompanying app_sources.json lists official repository URLs and frozen retrieval hashes for the 147 newly collected app adapters. Available upstream license text is copied without modification. License retrieval was not confirmed for recipesage, openfoodnetwork and fusionpbx; no license is invented for those entries. Collected local specs and their limited adapter checks do not establish execution of complete upstream services. No source README is supplied as an input to the isolated builder.
