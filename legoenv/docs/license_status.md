# Licenses

This page states the license of each part of the release.

| Part | License |
|---|---|
| First-party code | Apache-2.0 ([`LICENSE`](../../LICENSE)) |
| First-party data | CC BY 4.0, distributed separately from the code |
| Qwen weights | Upstream base-model terms |
| Third-party code and data | Their own upstream terms |

The data release's `DATA_LICENSES.tsv` is a per-source inventory, not a blanket
grant. Material with restricted, unknown or unresolved source or terms is excluded
from the public data. `tools/release_check.py` checks file hashes, not the licensing
of datasets or model weights. Notices: [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md);
license texts: [`third_party_licenses/`](../../third_party_licenses/).
