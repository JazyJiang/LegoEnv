# Independent public-workflow teaching example

Source workflow: https://hr.berkeley.edu/policies/policies-procedures/ppsm/berkeley-procedures/procedure-41

This example is reconstructed from a frozen web-source skeleton, with a new package ID. It uses the current fixture policy as the operative business instruction. Public source material motivates the workflow; locally chosen policy values and demonstration data are not represented as verbatim official policy.

Read build.py for the computed selected/skipped records, the rule carrier, state predicates and executable reference solution. Original package/source hashes and the original skeleton mapping remain in the private selection ledger. Local admission does not establish teacher success or an effect on the paired experiment.

Publication-path adaptation: only import path literals were made relative to the builder stack. Run from the staged workspace root (`tools/builder_workspace.py` places this directory under pack/). The reviewed full stack and its real datasets are required. The example is not an independent standard-library program.
